Cloud / Acerca de

Tu música.
Tu espacio.

Cloud nació para convertir una biblioteca local en una experiencia musical personal, expresiva y completamente tuya.

01

Local primero

Tu música permanece en tu equipo. Cloud organiza y reproduce tus archivos sin apropiarse de ellos.

02

Hecho para sentir

Letras sincronizadas, temas, fondos y pequeños detalles visuales acompañan cada canción.

03

Código abierto

Cloud se desarrolla de forma abierta para que la comunidad pueda estudiar, mejorar y compartir el proyecto.
