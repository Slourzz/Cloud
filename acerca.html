La idea

Cloud nació para que una biblioteca de Windows no se sienta como una carpeta de archivos. La música permanece en tu equipo; la experiencia crece alrededor de ella.

01

Propiedad real

Tus archivos, portadas y datos locales siguen siendo tuyos. Cloud no intenta sustituir tu biblioteca.

02

Expresión

Letras, temas, fondos y pequeños movimientos acompañan la intención de cada canción.

03

Comunidad abierta

El código y las contribuciones pueden estudiarse, corregirse y compartirse bajo una licencia libre.

Historia

Un proyecto que aprendió escuchando.

El comienzo

Una biblioteca con identidad

Cloud comenzó como una forma más personal de reproducir música local en Windows.

La evolución

Letras, temas y comunidad

Las letras sincronizadas, los temas inmersivos y las contribuciones convirtieron el reproductor en una plataforma creativa.

Ahora

Una experiencia conectada

Apple Music, Discord, extensiones y herramientas comunitarias conviven sin quitar protagonismo a los archivos locales.
